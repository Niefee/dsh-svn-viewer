# 变更记录

版本规则（2026-11-20 用户明确）：

- **默认只改 patch**（0.3.5 → 0.3.6 …）。即使这次改动是新增能力或宿主接口变化，也仍然只递增 patch，只在条目末尾标注「新能力」或「（需重启 dsh web）」。
- **minor 仅在用户明确要求时**才动（例如「升到 0.4.0」）；不擅自改中间位。
- 每次交付仍然是**唯一版本号**：本地安装链（profile `file:` + pnpm 缓存）用版本号当缓存键，同名 tgz 不可靠，所以同一版本不重复发包。
- 每次发包都补一条本记录（改了什么都记，不只是版本号）。

> 历史：0.2.0 是唯一一次真正的 minor（整轮 UI 重构）；0.2.1–0.3.4 均为一交付一 patch。下面的记录按实际内容标注，规则自下一条起生效。
